# 江湖未晚 · 三十日行记

一款单文件的武侠养成小游戏。你有三十天，在栖霞渡结交朋友、修习武学、挑战黑风寨，用自己的选择写下结局。

## 怎么玩

直接用浏览器打开 `江湖未晚.html` 即可，无需安装、无需联网，进度自动保存在浏览器本地。

- **每日奇遇**：每天一段剧情，三个选项会影响仁心、声望、心悟与朋友好感。
- **每日黄历**：每天随机的小加成，如「宜习武」「集市逢五」「忌刀兵」。
- **修行与历练**：每天 3 点行动，可习武、调息、帮工或外出战斗。
- **战斗**：先看敌方意图再出手。招架重击可「看破」，趁喘息出手可「乘隙」，偶有会心一击；胜后可能掉落稀有佩饰。
- **行囊**：分为背包、装备、武学三页。装备有兵刃、衣甲、头饰、手环、靴子、佩饰六个槽位；武学有招式、内功、身法三个槽位。
- **江湖称号**：达成目标解锁称号，可佩戴在名号前。
- **结局**：第 30 日歇息时根据你的经历写下结局，之后可继续自由游历。

快捷键：战斗中 `1`–`5` 对应各项操作，奇遇页 `1`–`3` 选择选项。右上角可开关音效。

存档：「存档」菜单可导出 / 导入 JSON 存档，换浏览器或换设备时使用。

## 目录结构

```
江湖未晚.html            游戏本体（图片以 base64 内嵌，单文件即可运行）
_art/
  江湖未晚.orig.html     原始版本备份，构建的起点
  build.py               构建脚本：压缩图片、注入代码，生成 江湖未晚.html
  fun.py                 黄历、战斗看破 / 会心、掉落、称号、音效
  bag.py                 行囊三分页、六槽装备、武学槽、物品图标
  qa.py                  无头浏览器回归：截图各页面、战斗与按键、存档往返、移动端布局
  out/                   AI 生成的原图（立绘、背景、结局图、icons/ 物品图标）
  ref/                   生成图片时使用的风格参考图
```

## 修改与重新构建

不要直接改 `江湖未晚.html`，它由构建脚本生成，改动会被覆盖。请修改 `_art/` 下的脚本，然后运行：

```bash
python _art/build.py
```

构建需要 Python 3 和 Pillow（`pip install pillow`）。每次构建都从 `江湖未晚.orig.html` 重新开始，可放心重复运行。

- 调整数值（物品属性、价格、黄历效果等）：改 `fun.py` / `bag.py` 中对应的数据。
- 替换图片：用同名 PNG 覆盖 `_art/out/` 中的文件，再构建。
- 新增物品图标：在 `_art/out/icons/` 放入与物品 id 同名的 PNG（如 `windboot.png`），构建时自动打包。

## 本地预览

也可以用简单的本地服务器打开：

```bash
python -m http.server 8765
```

然后访问 `http://localhost:8765/江湖未晚.html`。
